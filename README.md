# Carta Gantt Gerencia de Proyectos

Aplicación web para visualizar y reprogramar la cartera de proyectos mediante una Carta Gantt.

## Funciones principales

- Carga de archivos Excel y CSV.
- Reprogramación de fechas de inicio, término, duración e hitos.
- Indicadores y filtros por tipo de proyecto.
- Creación de nuevos proyectos con numeración entera o romana.
- Exportación a Excel, CSV y PDF con la visualización de barras.
- Funcionamiento local sin conexión una vez descargados todos los archivos.

## Uso en línea

La aplicación se publica con GitHub Pages desde `index.html`.

## Uso sin conexión

Descarga el repositorio completo y abre `index.html`. La carpeta `vendor` debe permanecer junto al archivo para conservar la importación de Excel y la exportación a PDF.

Los datos cargados o modificados permanecen en el navegador del usuario y no se envían a un servidor.
